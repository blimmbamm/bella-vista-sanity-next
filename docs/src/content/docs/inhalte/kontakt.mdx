Unter **Contact & business details** pflegst du die Stammdaten deines Restaurants. Sie werden an mehreren Stellen der Website verwendet: im Abschnitt **Contact details**, im Menü der Website (Adresse und Telefonnummer zum Reservieren) und im Fußbereich.

<Screenshot name="studio-kontakt" alt="Kontakt- und Betriebsdaten im Content Studio" />

## Die Felder

| Feld | Bedeutung |
| --- | --- |
| **Business name** | Name des Restaurants (Pflicht). Erscheint oben links auf der Website. |
| **Owner / authorized representative** | Inhaber oder vertretungsberechtigte Person (Pflicht, für die Anbieterkennzeichnung). |
| **Address** | Straße und Hausnummer, Postleitzahl und Ort sind Pflicht. |
| **Phone** | Telefonnummer. Gäste können sie auf dem Handy direkt antippen. |
| **Email** | E-Mail-Adresse für Gäste. |
| **VAT ID (USt-IdNr.)** | Umsatzsteuer-Identifikationsnummer, falls vorhanden. |
| **Map link** | Link zu Google Maps oder OpenStreetMap. In Google Maps: Restaurant suchen, **Teilen** anklicken, Link kopieren. |
| **Social media** | Links zu Instagram, Facebook, TikTok oder anderen Plattformen. |

Nach dem Ändern: **Publish** und [Deploy now](/veroeffentlichen/website-aktualisieren/).

<Aside type="caution" title="Rechtliche Angaben">
	Diese Daten werden auch für die Anbieterkennzeichnung verwendet. Halte sie aktuell, zum Beispiel nach einem Umzug oder Inhaberwechsel. Ob deine Angaben rechtlich vollständig sind, kann diese Anleitung nicht beurteilen, frag im Zweifel deine Steuerberatung oder einen Anwalt.
</Aside>
